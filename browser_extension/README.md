# 🛡️ CyberSentinel - Browser Network Defense Extension

**Turn Google Chrome, Microsoft Edge, Brave, or Opera into a live packet sniffer, tracker interceptor, and active network quarantine console!**

---

## ⚡ How to Install in Your Browser (10-Second Setup)

### In Microsoft Edge:
1. Open Edge and navigate to:
   ```text
   edge://extensions/
   ```
2. In the bottom-left sidebar, toggle **Developer mode** to **ON**.
3. Click the **"Load unpacked"** button at the top.
4. Select this folder:
   ```text
   C:\Users\hp\Documents\Antigravity project\PacketSniffer\browser_extension
   ```
5. Done! The **CyberSentinel 🛡️** icon will appear on your browser toolbar!

---

### In Google Chrome / Brave:
1. Open Chrome and navigate to:
   ```text
   chrome://extensions/
   ```
2. In the top-right corner, toggle **Developer mode** to **ON**.
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select the `PacketSniffer/browser_extension` folder.
5. Click the Extensions (puzzle piece) icon on your toolbar and **pin 📌 CyberSentinel**.

---

## 🚀 Key Features

- **Live Request Sniffer**: Intercepts all outbound HTTP, HTTPS, and WebSocket requests across all tabs.
- **Tracker & Beacon Interception**: Flags known telemetry, fingerprinting, and analytics domains (`doubleclick`, `google-analytics`, etc.).
- **Cleartext Insecure HTTP Warnings**: Alerts when credentials or assets travel unencrypted over port 80 HTTP.
- **1-Click Domain Quarantine**: Click **"Quarantine"** on any domain to instantly add it to your browser's active blocklist.
- **Full SOC Dashboard**: Click **"Full Dashboard"** in the popup to open the full-screen mission control view (`dashboard.html`).
- **Audit Export**: Export timestamped text reports of all network activity and flagged threats.
